# Guion breve para demostrar los avances

## Avance 1

“Usamos Git para mantener el historial del código y GitHub como repositorio remoto. Organizamos el trabajo en `main`, `develop` y ramas de funcionalidad. Los cambios se registran con commits descriptivos y se integran mediante Pull Requests. También practicamos merge y resolución controlada de conflictos.”

**Mostrar:** commits, branches, PR y evidencia de conflicto resuelto.

## Avance 2

“Complementamos el repositorio con GitHub Issues para registrar tareas e incidentes, Projects para visualizar el avance y Milestones para agrupar entregas. GitHub Actions ejecuta automáticamente la compilación y las pruebas con Maven. El flujo de Release permite publicar el artefacto compilado.”

**Mostrar:** Issues, Project, Milestones, Actions verde y Release.

## Avance 3

“Empaquetamos la aplicación con Docker para que pueda ejecutarse de forma consistente. La configuración se administra mediante variables de entorno y la aplicación se prepara para desplegarse en una plataforma cloud. Finalmente verificamos la URL pública y el funcionamiento de los módulos principales.”

**Mostrar:** Dockerfile, imagen/contenedor, proveedor cloud, URL pública, logs y prueba funcional. Si aún no existe despliegue público, decirlo como pendiente, no simularlo.
