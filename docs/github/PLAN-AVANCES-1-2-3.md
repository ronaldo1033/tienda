# Plan de trabajo y evidencias — Herramientas de Desarrollo

**Proyecto:** Tienda Integral  
**Repositorio remoto previsto:** https://github.com/ronaldo1033/tienda  
**Modalidad:** trabajo individual.  
**Alcance:** organizar evidencias de las Unidades 1, 2 y 3 del cronograma del curso.

> Este documento es un plan de ejecución y una lista de evidencias. No afirma que una actividad remota esté realizada. Marca cada punto solo después de ejecutarlo y guardar evidencia.

| Sesiones | Contenido del curso | Evidencia a producir |

| 5–6 | Repositorios, ramas y commits | Ramas `main`, `develop`, `feature/*`; historial de commits descriptivos. |
| 7–8 | Estrategias de ramificación y fusión | Diagrama de flujo Git y merge real entre ramas. |
| 9–10 | Conflictos y colaboración remota | Conflicto controlado resuelto y sincronización `fetch/pull/push`. |
| 11–12 | Nube y flujo básico; Avance 1 | Repositorio remoto, rama publicada, CI ejecutada y capturas. |
| 13–14 | Trabajo colaborativo en la nube | Issues, Projects y Pull Request. En modalidad individual, usar PR como revisión personal; no inventar revisores. |
| 15–16 | Pull Requests, Merge Conflict y Release | PR fusionado, conflicto documentado y Release/tag real. |

## Evidencias mínimas para la exposición

1. Repositorio y README actualizado.
2. Historial de commits con mensajes claros.
3. Vista de ramas `main`, `develop` y rama de trabajo.
4. Pull Request con descripción, revisión personal y merge.
5. Ejemplo real de conflicto resuelto (sin dejar marcadores `<<<<<<<`).
6. GitHub Projects y Milestones.
7. Issues de tareas y al menos un incidente de prueba claramente identificado como ejemplo.
8. Actions con ejecución verde de Maven.
9. Release con artefacto generado por el workflow.
10. URL de despliegue cloud comprobada y capturas.

## Declaración de trabajo individual

El proyecto lo desarrolla una sola persona. Se utilizarán ramas y Pull Requests para separar cambios y realizar revisión propia. No se presentarán cuentas ficticias, revisiones inventadas ni actividad colaborativa simulada como si fueran aportes de otras personas.
